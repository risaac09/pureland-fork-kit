# Field testing

This is the testing discipline that runs alongside [the journey](JOURNEY.md); the ground and return stations use it directly. Field tests should try to break the method. Confirmation alone is weak evidence.

## Before use

1. Name the practice, system boundary, purpose, and affected people.
2. Choose one instrument and state why.
3. Record the evidence available before scoring.
4. Obtain permission for any participant material. Do not submit private material.
5. Write one result that would count against the method.

## During use

- Keep missing evidence as `unmeasurable`.
- Record time required and who did the work.
- Ask a second reader to work independently when possible.
- Preserve category disagreements and participant objections.
- Do not calculate a composite.

## After use

Submit the [field-test template](templates/field-test.md) as an issue or pull request. A useful report includes failure, burden, and context. The maintainer will add accepted reports to [FIELD-TRIALS.md](FIELD-TRIALS.md) with links, not rewrite them as endorsements.

## Minimum comparison for a bounded adaptation

Record a baseline, the change, the intended benefit, a plausible new harm, the observation window, and the follow-up evidence. Causal claims require more than a before-and-after impression.

No participant recordings, transcripts, names, contact details, or protected community knowledge belong in a public report.
