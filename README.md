# PureLand

PureLand is an open method for increasing attention sovereignty without making people easier to extract from. It combines contemplative self-observation, information-practice analysis, bounded adaptation, and accountable return.

This is a version 0.1 research prototype. It is not validated, does not certify openness or safety, and makes no independent field-result claim.

## What can I do here?

- Read the [brief](BRIEF.md) for the goals, method, offering, accountability, and open questions.
- Propose or scope a [PureLand Field Pilot](OFFERING.md).
- Use the [instruments](SCORECARD.md), [extraction check](EXTRACTION-CHECK.md), and [protocol](PROTOCOL.md).
- Read the [open-research lane](research/README.md) and [research status](RESEARCH-STATUS.md).
- Contribute a correction, field test, disagreement, or adaptation through [CONTRIBUTING.md](CONTRIBUTING.md) and [GOVERNANCE.md](GOVERNANCE.md).
- See the [visual language](design/VISUAL-LANGUAGE.md) the kit's own visuals follow.

## Where should I start?

Start with [BRIEF.md](BRIEF.md). If you are bringing one real information practice for bounded co-inquiry, read [OFFERING.md](OFFERING.md). If you want to apply an instrument yourself, read [FIELD-TESTING.md](FIELD-TESTING.md) first.

The repository contains methods and templates. It does not contain participant recordings, transcripts, identifying data, confidential records, protected community knowledge, or a worked field example. See [LICENSE.md](LICENSE.md) and [RIGHTS-AND-CONSENT.md](RIGHTS-AND-CONSENT.md).
