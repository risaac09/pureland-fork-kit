# (Pure)Land: a fork kit

Public, open source, licensed [CC BY-SA 4.0](LICENSE.md). Fork it, run it on your own practice, argue with it.

## What's here

Five things, meant to be forked, argued with, and changed:

- **[PROTOCOL.md](PROTOCOL.md)**, how to hold a recorded conversation with someone you're in relationship with, without the recording becoming a taking.
- **[SCORECARD.md](SCORECARD.md)**, a blank instrument for measuring how openly any practice, archive, or organization actually moves: whether an outsider can read it, whether information crosses in and out, whether it can be forked without asking, whether its claims trace back to a source.
- **[EXTRACTION-CHECK.md](EXTRACTION-CHECK.md)**, the check every openness reading has to be paired against, because opening a system and making it easier to exploit are often the same move wearing different language.
- **[example/synthetic-example.md](example/synthetic-example.md)**, all five parts worked through on an invented case, so you can see the instruments filled in before you fill in your own.
- **[PROVENANCE.md](PROVENANCE.md)**, what this kit builds on, what it hasn't proven yet, and every citation checked against a primary source rather than taken on faith.

License and the reciprocity expectation that goes with it: [LICENSE.md](LICENSE.md).

## The one claim underneath all five

A self, an organization, or a practice becomes what it is at the threshold where it meets something else, not before. The recorded conversation is the smallest unit of that claim: two people meet, something arises that belonged to neither of them beforehand, and what gets kept from that meeting owes something back to where it came from.

That's not a sentiment bolted onto a facilitation practice. It's also a description of what's wrong with the architecture most of us live inside now. An information ecosystem built to fragment attention isn't malfunctioning. Fragmentation is the extraction method: a mind that stays gathered consumes less, generates fewer moments where presence converts into inventory. Every one of the four accesses this kit measures, whether something can be read, crossed, forked, or traced, is a property that architecture already has, whether anyone built it on purpose or not. This kit exists because a mind that's been trained to scatter needs instruments built for a mind trying to gather, and most instruments for measuring openness weren't built with that in mind.

## Five questions, if you only have a minute

Before the instruments, five questions any of this can be asked of, a feed, a model, a facilitation practice, a research archive, an institution:

1. Does it keep what it touches alive, or does it collapse the living thing into a residue and trade the residue?
2. Does it take only what's given, or does it take what was never offered?
3. Does it honor the intimacy it has access to, or does it simulate closeness to hold attention?
4. Does it speak with a traceable source, or does it generate claims with no origin anyone can check?
5. Does it gather the mind that uses it, or does it fragment that mind on purpose because a scattered mind is worth more to it?

Those five map, loosely and openly, onto the oldest vow structure available for thinking about contact between beings, the five precepts. That mapping is this kit's own synthesis, not a claim about what the precepts are for. Full sourcing and every citation checked against a primary text: [PROVENANCE.md](PROVENANCE.md).

## What this kit is not

Not a finished instrument. The scorecard has been run once, informally, on the practice that produced it, and that single run doesn't prove it generalizes. Not proof that the underlying thesis is right. Not a claim to be first: InsightShare built a version of this years before, at real scale, and this kit cites them because that's the first thing reciprocity requires. Full account of what's built versus what's still just specified: [PROVENANCE.md](PROVENANCE.md).

## What to do with it

Use it, break it, or ignore it. If you use it: fork it under the terms in [LICENSE.md](LICENSE.md), which means whatever you build on this stays open too. If you find something, a place the scorecard didn't fit, a place the protocol assumed something about your situation that wasn't true, a disagreement with the whole premise, send it back. A question, a fork with a real change, an application to your own work, a disagreement you can back up: all of that counts as contact. A star or a quiet download doesn't, not because it isn't appreciated, but because this kit only learns whether any of this is real from someone outside the room where it was built actually pushing on it.

Open an [issue](https://github.com/risaac09/pureland-fork-kit/issues) or a [discussion](https://github.com/risaac09/pureland-fork-kit/discussions) on this repo, or send a pull request with the change itself.
