# PureLand

PureLand is an open method for taking back control of your attention without making yourself easier for other systems to exploit. It combines four things: quiet self-observation drawn from contemplative practice, a close look at how an information practice actually works, one small change tested at a time, and an honest account of what came back.

This is a version 0.1 research prototype. It has not been validated. It does not certify that anything is open or safe, and it makes no claim about field results.

## What can I do here?

- Read the [brief](BRIEF.md) for the goals, the method, the offering, the accountability rules, and the open questions.
- Propose or scope a [PureLand Field Pilot](OFFERING.md).
- Use the [scorecard](SCORECARD.md), the [extraction check](EXTRACTION-CHECK.md), and the [protocol](PROTOCOL.md).
- Read the [open-research lane](research/README.md) and the [research status](RESEARCH-STATUS.md).
- Contribute a correction, a field test, a disagreement, or an adaptation through [CONTRIBUTING.md](CONTRIBUTING.md) and [GOVERNANCE.md](GOVERNANCE.md).
- See the [visual language](design/VISUAL-LANGUAGE.md) the kit's own visuals follow.

## Where should I start?

Start with [BRIEF.md](BRIEF.md). If you want to bring one real information practice for a small, bounded inquiry, read [OFFERING.md](OFFERING.md). If you want to score something with an instrument yourself, read [FIELD-TESTING.md](FIELD-TESTING.md) first.

The repository contains methods and templates. It does not contain participant recordings, transcripts, identifying data, confidential records, protected community knowledge, or a worked field example. See [LICENSE.md](LICENSE.md) and [RIGHTS-AND-CONSENT.md](RIGHTS-AND-CONSENT.md).
