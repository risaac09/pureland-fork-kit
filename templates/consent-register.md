# Consent register

Store this record securely. Keep it outside the public repository. Do not place a completed register in a public issue, pull request, field report, or AI system without a separate, authorized reason.

Use one register for each participant or rights holder. Add a separate community-authority record when a community holds the decision. This template records project decisions. It is not universal legal language.
