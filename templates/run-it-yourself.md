# Run it yourself

## Purpose

Use this worksheet to run the six steps of [the PureLand method](../METHOD.md) on one bounded information practice. The linked instruments define the work. This packet adds no score, finding, or interpretation.

[CURRENT-EVIDENCE.md](../CURRENT-EVIDENCE.md) states what PureLand has shown. A completed worksheet does not raise that evidence ceiling.

## Choose the size of the run

A private run can stay in your own notes or leave no record. Use the short path in [METHOD.md](../METHOD.md#running-it-privately) if that is what you need.

Use this packet when you want a record you can revisit. Keep it private by default. A result that enters the public research record needs the full [field-test report](field-test.md), structured record, rights review, and artifact-version public-safe decision.

## Report

Return after the observation window. Record what changed, what did not, and what remains missing. Choose one ending:

- keep a private result;
- stop or refuse;
- record `unmeasurable` and name the missing evidence;
- prepare a public-safe return through [CONTRIBUTING.md](../CONTRIBUTING.md).

An outcome-capable run needs an affected person to challenge the reading. Their correction or disagreement stays in the record when rights permit. A public report and structured record require a `clear` public-safe decision for the exact artifact versions.

## Limits

This packet cannot supply another person's permission, an affected person's challenge, elapsed follow-up time, or an independent reading. The repository checker tests structure and cross-file consistency. It does not establish completion, validity, safety, or outcome.
